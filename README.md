⚙️ Tecnologías usadas

React: Biblioteca de JavaScript para construir interfaces de usuario.

Vite: Herramienta de desarrollo que ofrece una configuración rápida y soporte para HMR (Hot Module Replacement).

ESLint: Herramienta para analizar el código y detectar posibles errores.

@vitejs/plugin-react: Plugin oficial de Vite para integrar React, con soporte para HMR y otras funcionalidades.

Oxc: Herramienta utilizada por @vitejs/plugin-react para transformar el código.
JavaScript: Lenguaje utilizado para desarrollar la aplicación.

🚀 Instalación y ejecución
Clonar el repositorio:
   git clone URL_DEL_REPOSITORIO
Entrar en la carpeta del proyecto:
   cd nombre-del-proyecto
Instalar las dependencias:
   npm install
Ejecutar el servidor de desarrollo:
   npm run dev
Abrir en el navegador la dirección local que muestra la terminal, normalmente https://alisonrave13-beep.github.io/PPI/
Para generar una versión de producción:

npm run build
Para comprobar el código con ESLint:

npm run lint

🔑 Variables de entorno
La plantilla básica de React + Vite no requiere variables de entorno obligatorias por defecto.

Si se integran servicios externos o una base de datos, se pueden definir variables en un archivo .env, por ejemplo:

VITE_API_URL=
VITE_API_KEY=
Los valores dependerán de los servicios utilizados. Las variables con el prefijo VITE_ pueden quedar expuestas en el código del navegador, por lo que nunca se deben incluir claves secretas ni credenciales privadas.

📁 Estructura del proyecto

public/: Archivos estáticos públicos.
src/: Código fuente principal de la aplicación.
assets/: Imágenes, iconos y otros recursos.
App.jsx: Componente principal de React.
main.jsx: Punto de entrada de la aplicación.
index.css o App.css: Archivos de estilos, según la configuración.
index.html: Documento HTML principal.
package.json: Dependencias, información y scripts del proyecto.
vite.config.js: Configuración de Vite y sus plugins.
eslint.config.js: Configuración de las reglas de ESLint.

✨ Funcionalidades
Desarrollo de interfaces de usuario mediante componentes de React.

# Cryptonguard
Pagina para obtener informacion de las monedas y saber de reseñas de vendedores 

R \\sirven para vincular el supabase y para crear el link donde se puede ver la aplicacion 

📁 Estructura del proyecto

src/components → Componentes reutilizables de React, como tarjetas con el precio de Bitcoin, gráficos y botones de navegación.

src/pages → Vistas principales de la aplicación, como la página de inicio, el precio de Bitcoin, las estadísticas del mercado y el historial de precios.

src/supabaseClient.js → Configuración de la conexión a Supabase para almacenar y consultar datos de la aplicación.

src/App.jsx → Componente principal que organiza las páginas y los componentes de la aplicación.

src/main.jsx → Punto de entrada de React que permite iniciar la aplicación.

src/assets → Imágenes, iconos y otros recursos gráficos relacionados con Bitcoin.
